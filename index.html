Queue · คิวทั่วไป

ใช้ Linked List ที่เก็บทั้งหัวและท้ายคิว เพิ่มเหตุที่ท้ายและนำออกจากหัวตามลำดับมาก่อนออกก่อน (FIFO) อาร์เรย์ที่นำสมาชิกตัวแรกออกด้วยการเลื่อนสมาชิกจะใช้ O(n) ต่อครั้ง

เพิ่มท้ายคิว · enqueue
O(1)
นำหัวคิวออก · dequeue
O(1)
ดูหัวคิว · peek
O(1)
แสดงรายการทั้งหมด
O(n)

Min-Heap · คิวด่วน

ให้เหตุระดับ 1 อยู่ก่อนระดับ 2–5 ระดับเท่ากันใช้ลำดับที่แจ้งเข้ามาตัดสิน คิว FIFO เดียวจะหยิบรายการแรกได้ O(1) แต่ถ้าจะหาความด่วนสูงสุดต้องไล่ดูถึง O(n)

เพิ่มเข้าคิวด่วน · insert
O(log n)
นำเหตุที่ด่วนที่สุดออก · extract_min
O(log n)
ดูเหตุที่ด่วนที่สุด · peek
O(1)
แสดงรายการตามลำดับ
O(n log n)

ลำดับที่ระบบเลือกตรวจ

ระบบเลือกเหตุจาก Min-Heap ก่อน หากคิวด่วนว่างจึงเลือกหัว Queue ส่วนการแสดงคิวด่วนทั้งหมดใช้สำเนา Heap เพื่อรักษาคิวจริงไว้

Big-O ข้างต้นวัดเฉพาะการทำงานของโครงสร้างข้อมูล โดย n คือจำนวนรายการในคิวนั้น ส่วนการบันทึกไฟล์และแสดงผลหน้าเว็บมีต้นทุนแยกต่างหาก
